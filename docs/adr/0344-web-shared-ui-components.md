# ADR-0344: 共通の UI 部品(G-05 / I-web-13a)

- 状態: 採用(2026-10-11)
- 関連: ADR-0339(見た目の作り直し方針)・ADR-0334/0336(共通の部品)・ADR-0341(技ピッカー)・ADR-0343(ポケモンの画像)

## 決めたこと

docs/design.md「部品の一覧(G-05)」の部品を `web/src/ui/` に実装した(画面への適用は I-web-13b 以降)。方針に無かった細部を次のように決めた。

1. **区切りボタン(`SegmentedControl`)**: `role="radiogroup"` + `role="radio"`、roving tabindex、矢印キーで選択とフォーカスが一緒に動く(端で回る・Home/End)。選択肢は 2〜4 個で、外れると例外を投げる(5 個以上はチップ)。選択中は塗り + チェックのアイコンで示す(色だけに頼らない)。
2. **増減ボタン(`Stepper`)**: 数値欄は残し、− / + は 44px の丸。名前は「<欄の名前>を増やす/減らす」(用語集「共通の部品の語」)。範囲に収めて通知し、打っている途中(空)は通知せず、欄を離れると元の値に戻す。
3. **シート(`Sheet`)**: `document.body` へのポータル。`role="dialog"` + `aria-modal`。フォーカス・Esc・Tab の循環・閉じたとき開いた要素へ戻すのは「このアプリについて」の `alertdialog` と同じ。幕を押すと閉じる。狭い幅(600px 未満)は下から、600px 以上は右の面。出入りは transition だけ(`animation` は使わない)で、時間は新トークン `--duration-sheet`(0.25 秒。reduced-motion で 0)。閉じるときは `--duration-sheet` の分だけ DOM に残してから外す(0 のときはすぐ)。
4. **幕の色**: 新しい色トークンを足さず、`shadow.color` を 3 枚重ねて暗くする(ダークで明るくならない)。
5. **枠の色**: 区切りボタン・増減ボタン・タイル・数値欄の枠は `text.secondary`(カードの上で 3:1 以上。`popPalette.test.ts` の組み合わせ表に足した)。既存の `border.hairline` は装飾の線なので部品の境界には使わない。
6. **アイコン**: `close`・`open`(下向きの山)・`history`(時計)・`help`(?)・`up`・`down` と、増減ボタン用の `minus` を足した。`TypeBadge` を技ピッカーから `ui/` へ移して共有する。

## 理由

操作の作法(ラジオ・ダイアログ)は既存の作りと WAI-ARIA に合わせ、画面側が部品を差すだけで済むようにするため。色・時間はトークンだけにし、新しい色の組は検査に足す。

## 追記(critic の指摘への対応)

- `Stepper` の端(上限・下限)は `disabled` ではなく `aria-disabled` にし、クリックを無視する(押した直後にフォーカスが body に落ちないため)。範囲外の打ち込みは blur / Enter で範囲に収め(min が 0 でない欄でも途中の桁を打てる)、範囲内になったときだけ打ちながら通知する。親が value を外から変えたら打っている途中の文字は捨てる。**長押しのリピートは作らない**(連続変更は数値欄に打つ)。
- `Sheet` は開いている間 body のスクロールを止め、`body` 直下の他の要素に `inert` を付ける(`ui/modalLock.ts`。回数で数えるので重なっても壊れない)。Esc は document で拾い、一番上のシートだけが閉じる。幕は押し始めも幕の上だったときだけ閉じる。
