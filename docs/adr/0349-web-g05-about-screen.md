# ADR-0349: このアプリについての作り直し(G-05 / I-web-13i)

- 状態: 採用(2026-10-11)
- 関連: ADR-0339(方針)・ADR-0314(このアプリについて)・ADR-0318(端末データの削除)・ADR-0348

## 決めたこと

docs/design.md「画面ごとの方向」のこのアプリの行を実装した。この画面は「説明そのものが目的」の例外なので、文は残し、見やすくする。

1. 3 節(非公式表示・データの出典・データの扱い)の見出しはアイコン + 名前(注意・情報・丸の i。装飾)。
2. 文面は変えない。非公式の注記・出典 4 件(MIT License の表記を含む)・データの扱いの 4 文(4 文目も残す)は一字一句そのまま。
   iOS の文言との一致・ADR-0002 の出典の責務を崩さないため、短縮や HelpButton への格納はしなかった(既存テストも全文の表示を前提にしている)。
   代わりにデータの扱いの 4 文を 1 文ずつの箇条(`ui-rows`、読み上げは list)にして目で追えるようにした。
3. 削除ボタンはごみ箱アイコン + 従来の文字(読み上げ名は従来のまま)の危険ボタン。確認ダイアログの見出しに注意アイコン、「削除する」にごみ箱アイコン。
   確認ダイアログの作法(初期フォーカスはキャンセル・Esc で閉じて削除ボタンへ戻す・Tab の循環)は変えない。

## 影響

新しい色の組・アニメーションは無い。既存テストの付け替えは無い。
