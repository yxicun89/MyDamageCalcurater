# ADR-0006: 確定数/乱数n発の確率モデル

- 状態: 承認
- 日付: 2026-09-21
- 関連: docs/test-strategy.md、CLAUDE.md 絶対ルール7、ADR-0010 §3.4(P1-11: 表示用の確率)

## 背景

「確定n発 / 乱数n発(x%)」を算出する必要がある。16段階のダメージロールから、n発で
倒せるかどうかと、乱数の場合の確率を求める。

## 決定

- 16段階のロールはそれぞれ **独立・一様(各 1/16)** に出ると仮定する。
- KO 閾値は **累計ダメージ >= HP**(HP が 0 で瀕死、ポケモン仕様)。
- 倒すのに必要な最小攻撃回数 `Hits = ceil(HP / 最大ロール)`。最大ロール 0(無効・ダメージ0)は
  `Hits=0`(倒せない)。
- `最小ロール × Hits >= HP` なら **確定**(Guaranteed)。ChancePercent は使わない(0 のまま)。
- 確定でなければ **乱数**。ChancePercent は「n 発の合計が HP 以上になる確率」を
  16ロールの畳み込み(動的計画法)で厳密に求める。HP 以上の合計は1つのバケットに吸収する。
- 確率は表示用の float。ダメージ計算本体(4096基準の固定小数)には float を持ち込まない。
- **`ChancePercent` は生値であって画面に出す値ではない**(P1-11 で明確化)。確定のとき 0、
  倒せないとき(`Hits=0`)も 0 なので、そのまま表示すると「確定n発なのに 0%」になる。
  画面に出す値は `KOChance.DisplayChancePercentTenths()`(0.1% 単位。確定は 1000 = 100.0%、
  倒せないときは 0、それ以外は四捨五入して [1, 999] に収める)。**生値の意味は変えない**:
  `tools/golden/generate.mjs` が確定時に `ChancePercent: 0` を期待値として書いており、
  ゴールデン(`make test-golden`)がこの意味に依存しているため。詳細は ADR-0010 §3.4。

## 却下・保留

- 端数回復(たべのこし)・反動(いのちのたま)・毎ターン定数ダメージ(どく・すなあらし)を
  絡めた多ターン KO は M1 では扱わない。単発の技を n 回当てる単純モデルに限定する。
- 急所率・命中率は確率に含めない(常に命中・非急所を既定とする)。

## 影響

- engine/ko.go に実装。DamageResult.KO に格納。API の KOChance にマッピングする(P3)。
- モデル拡張(端数回復など)は本 ADR を更新する。
