# ADR-0711: 判定画面の技 select・調整プリセット・「詳細」・欄ごとの検証エラー

- 状態: 採用(2026-10-02。判定レーンの判断。issue 309)
- 日付: 2026-10-02
- 関連: ADR-0705(JD5。§5 の「技は ID 自由入力」を置き換える)、ADR-0304(§3 は getMove・resolveSpecies の技〈A-13〉で解消済み)、
  ADR-0300 §5(攻撃側プリセット)、ADR-0009 §1(防御側プリセット)

## 背景
判定画面は技・SP・ランクを数値や ID で直接打たせており、操作が重かった。計算画面は既に「種族の learnset から技を選ぶ」
「プリセットで SP と性格を入れる」形になっている。ADR-0304 §3 の欠落(技を ID から引けない)は解消済み。

## 決定
1. **技は select に変える(ADR-0705 §5 を置き換え)**。選択肢は選んだ種族の learnset の順(変化技を含む)。
   既定は最初のダメージ技(`firstDamagingMove`)。種族を替えたら新しい種族の既定へ。request の `moveId` は選んだ `Move.id`。
   自分も候補も同じ部品。オンライン(`masterSearch`)は `onResolved` の `resolution.moves` から引く(新しい API は不要)。
2. **learnset を引けないとき(空・実体を解決できない)は ID の自由入力へ戻さない**。select を disabled のまま
   「この種族の技を読み込めません」を出し、送信は必須の検査で止める(技 select は aria-invalid)。逃げ道を作ると、
   存在しない ID を送らせて 422 を返す旧挙動が復活するため。
3. **調整はプリセット(radiogroup「調整」)**: 無振り(既定)・最速・攻撃特化・HB特化・HD特化。無振り・攻撃特化・HB/HD特化は
   既存の `resolveAttackerPreset` / `resolveDefenderPreset` を再利用。**最速は判定画面固有**で Web 側に定義する
   (SP の素早さに全振り + 素早さ上昇の性格。下降は物理技なら特攻〈ようき〉、特殊技なら攻撃〈おくびょう〉)。性格は
   `master.natures` から (plus, minus) 一致で引く(ハードコードしない)。技を替えてもプリセットの選びは保ち、
   分類が変わるときだけ SP・性格を再解決する。SP・性格を手で変えて値が食い違えば、どのラジオも選ばない(値は手入力のまま)。
4. **SP6欄・ランク5欄は `<details>`「詳細」に畳む**(初期は閉。開閉は体ごと。閉じても値は残り送信に使う)。
   `<details>` の暗黙の group ロールは外す(`role="none"`。相手候補の fieldset〈group〉と数えが混ざるため)。
5. **検証エラーは欄ごとに出す**: 該当欄に aria-invalid と aria-describedby(「自分」または「相手候補n: 理由」)。
   SP 範囲外は該当 SP 欄、合計超過はその体の SP 6 欄、ランク範囲外は該当ランク欄、必須の空は種族・性格・技。複数の体の誤りを同時に出し、
   「詳細」内の誤りは送信時に自動で開く。従来の `role="alert"` の全体メッセージは残す。
6. 種族を選んだとき、性格が未選択でプリセットを選んでいる(既定は無振り)なら、そのプリセットの SP・性格を入れる(手で選んだ性格は上書きしない)。
7. 全体メッセージ(role="alert")の優先順位は 必須 → SP 範囲 → SP 合計 → ランク(体をまたいで先に判定。従来は体ごと)。欄ごとの文言は全ての誤りを出す。
8. SP 欄を空にしたら 0 に戻す(キー入力で全消去 → 入れ直しができるように)。

## 却下した案
- 技の ID 入力欄を残す(フォールバック): 決定 2 の理由。
- 最速を共通のプリセットに追加する: 計算・逆算には不要で、他画面のファイル(レーン境界。ADR-0705 §1)に触れる。

## 影響・提案
- `web/src/judge/` の中だけを変更(`individualForm.ts`・`judgeValidation.ts` を追加)。judge API 契約・`judgeClient.ts`・他画面は無変更。
- CalcScreen の `MoveSelect` / 攻撃側プリセットの選択部品は judge 内に写した。**共通部品化は別タスクとして提案**する。
- `SpeciesSearchField`(検索欄)は aria-invalid を受けられないため、オンラインの種族欄の欄別エラーは文言の段落だけで示す(別タスク)。
