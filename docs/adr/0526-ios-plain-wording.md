# ADR-0526: iOS の文言のやさしい言い換え(用語集に合わせる) — F-13

- 状態: 採用(2026-10-11)
- 関連: docs/usability-round2.md F-13、ADR-0337(Web。§4 の対応表が正)、docs/glossary.md、
  docs/ai-shared/decisions/2026-10-04-web-plain-wording.md、ADR-0501(受け入れ条件の記録)、ADR-0509(メガの持ち物固定の文言)

## 決定

1. iOS の画面に出る文字列を、ADR-0337 §4 の対応表と同じ文(同じ意味の Text は同じ文)にする。
   対象は `PokeCalcKit` の文言の型(`AdjustText`・`SpeedLabels`・`BalanceErrorText`・`MegaItemText`・`DeviceDataText`・
   `RequestLimitLabels`・`FavoritesLabels`〈読み込みの通知〉・`ReverseCandidateDisplay`)と `ios/PokeCalc/` の Text・accessibilityLabel。
   コメント・型名・変数名・accessibilityIdentifier・API のコード値(`16n` などの列挙の raw value)は変えない。
2. Web に同じ文が無い iOS だけの文言は、用語集の言い換えに従って決める。
   - 逆算の候補の一致表示: 「観測と一致」→「入力したダメージと一致」(件数表示も同じ)。
   - 逆算の行: 「観測を追加」→「ダメージを追加」、「観測n(単位)」→「ダメージn(単位)」、「この観測を削除」→「このダメージを削除」。
   - 上限の通知: 「観測は最大N件までです」→「ダメージは最大N件まで入力できます」(Web の `observationLimitReached` に合わせる)。
   - 接続先の表示: 「APIに接続中(host)」→「サーバーに接続中(host)」。
   - 内部の通信まわりのエラー(計算に必要なポケモンのデータが足りない・技がデータに見つからない)の「種族」「マスタ」→「ポケモンのデータ」「データ」。
3. 判定画面(`JudgeLabels`)は F-07 で非表示・判定レーン担当のため触らない(用語集の例外と同じ)。モック(`Mock*Service`)の開発者向けエラーも画面に出ないので触らない。
4. 「種族」は「すべての特性」の意味のときだけ禁止語(用語集)。お気に入り読み込みの注記「攻撃側には、種族・性格…」のようにポケモンそのものを指す説明は Web も残しているので変えない。
5. 検査: `GlossaryTests`(PokeCalcKit)が、列挙できる画面の文言(上の型の値・エラー表・確定数の文)に禁止語(用語集の表の1列目をテスト内に持つ。
   「ID」は単語としてのみ、「のメガストーン」は「専用のメガストーン」を除く)が無いことと、変えない語(確定・乱数・性格・特性・持ち物・能力ポイント・実数値・仮想敵・メガストーン・メガシンカ)が
   残っていることを確かめる。用語集を実行時に読まない(テストがリポジトリのドキュメントの位置に依存しないため)。用語集を変えたらこのリストも変える。

## 影響

- 文言だけの変更。API・engine・キー(識別子)は変えない。UI テストは識別子で探すので、ラベルや本文で比べている箇所だけ新しい文に合わせた(ADR-0501「F-13」章の表)。
