# ADR-0008: 外部照合に基づく補正段階の訂正

- 状態: 採用
- 日付: 2026-09-21
- 関連: P1-6、ADR-0004 / ADR-0005 / ADR-0006

## 背景と根拠

Claudeからの引継ぎ時、`make test-golden` は `[no tests to run]` で正常終了していた。
既存ユニットテストは手計算した期待値を用い、ADR-0004のSTAB説明も外部実装と異なっていた。
ロック済み `@smogon/calc 0.10.0` の `dist/mechanics/util.js:getFinalDamage` と
`gen789.js:calculateBPModsSMSSSV / calculateAtModsSMSSSV / calculateDefenseSMSSSV /
calculateFinalModsSMSSSV` を確認し、同一入力をNodeから実行して不一致を再現した。

## 訂正

1. STAB は五捨五超入を済ませてから相性を掛け、floorする。丸めを統合しない。
2. フィールド・タイプ強化持ち物・分類限定強化持ち物は威力段階で連結して丸める。
3. あついしぼう等の `DefResistType`、タイプ強化特性の `OffBoostType` は攻撃実数値段階。
   持ち物との連結順は攻撃特性、相手の特性、攻撃側持ち物。
4. 砂/雪の防御実数値を先に丸め、次に持ち物倍率を適用して丸める。
5. 最終倍率は壁、抜群軽減特性、攻撃持ち物、半減きのみの順で連結する。
   ノーマル半減きのみは等倍でも発動する。
6. 実数値がLv50固定であるため、計算入口では未指定(0)またはLv50だけを受け付ける。
   OpenAPIの明示レベルは50に制限する。負の種族値も拒否しゼロ除算を防ぐ。

ItemEffectに `PowerMod / PowerCategory` を追加し、最終倍率 `DamageMod` と区別する。
効果は引き続き外部データとして受け取り、engineに持ち物一覧を追加しない。
接地・テラス・ダブル等、ADR-0005の未対応範囲を今回完成扱いにはしない。

## 既存テストの期待値を変える理由

A/C=200、B/D=100、威力100、Lv50、無補正、特性・持ち物なしを基準とした外部結果:

| ケース | 旧期待値 | 外部実装の値 |
|---|---:|---:|
| 水STAB→岩、乱数86 | 231 | 230 |
| エレキフィールド、最大 | 117 | 116 |
| ミストのドラゴン技、最大 | 45 | 46 |
| あついしぼうの炎技、最大 | 45 | 46 |
| もくたんの炎技、最大 | 108 | 107 |
| D=101、砂+岩+チョッキ、威力108の特殊技、最大 | 43 | 44 |

期待値の訂正はテストを通すための緩和ではなく、外部実装から確認できる誤りの修正。
回帰テストを先に失敗させてから実装を訂正した。この理由をコミットメッセージにも残す。

## 検証と範囲

生成器とコミット対象のベクタを用いて16ロールと実数値を照合する。
KOはADR-0006の「同じ単発分布を独立にn回」モデルを外部ダメージから独立に算出する。
smogonのターン間天候ダメージ・きのみ消費・回復を含むKOとは区別する。
P2の使用可能マスタ確定前のgen9参考集合をチャンピオンズ全使用可能種の保証と呼ばない。
データ不在・空集合は失敗とし、既知差分の追加で不一致を隠さない。
