# ADR-0346: 逆算画面の作り直し(G-05 / I-web-13c)

- 状態: 採用(2026-10-11)
- 関連: ADR-0339(方針)・ADR-0344(共通の部品)・ADR-0345(計算画面)・ADR-0300 §11(観測のデバウンス)

## 決めたこと

docs/design.md「画面ごとの方向」の逆算の行を実装した。方針に無かった細部を決める。

1. **自分・相手は `PokemonCard`(名前は h3)**。持ち物の印は持ち物欄がある自分だけ(メガ種族は固定のストーン)。相手は持ち物を探索する側なので印を出さない(固定のメガストーン名の 1 行は従来どおり)。ポケモン・持ち物の選択は計算と同じく select のまま。
2. **ダメージの側(与えた/受けた)・単位(%/HP)は `SegmentedControl`**。自分の調整(3〜5 択)は計算と同じチップ(`ToggleChip`。`className` を足した)。
3. **候補はカード**。1 行目は型の名前(補正なし/B上昇)と目安の名前のバッジ、「ほぼ合う候補」はバッジ(danger の枠)、右に予測%の大きい数字、次にバー、その下に SP の範囲(「参考」はバッジ)・持ち物・特性を小さく。バーは**予測ダメージ%の上限**(100% で満ちる。装飾なので `aria-hidden`)。「一致の度合い」は engine が返す値に無く、TS で再判定しない(ADR-0300 §8)ため、一致/不一致はバッジで示す。
4. **種族検索欄(共通 `SpeciesSearchField`)の補足の文は「説明」ボタンの奥**(計算・逆算・タイプバランス・構築の共通)。常時出す文は状態の 1 行(「名前を入力してください」等)だけ。補足の文を指していた `aria-describedby` は無くなった。
   - 代償: 説明ボタンを開くまで、スクリーンリーダーは combobox から補足を得られない。
   - 許容する理由: 補足は前方一致の入力の仕方という任意の手がかりで、操作の必須情報ではない。
   - 代わりの手がかり: 見えるラベルは常にある・入力前/0 件/失敗の状態の 1 行は残る・説明ボタンが `aria-expanded` / `aria-controls` で補足と結ばれる。
5. 観測欄の単位・側の説明 1 行(`observationHintLabel`)は、方針の「単位の 1 行」として残した(入力欄の `aria-describedby`)。

## 影響

新しい色の組は無い。観測のデバウンス・中止・候補比較・メガ固定・オンライン時の無効化は変えていない。
