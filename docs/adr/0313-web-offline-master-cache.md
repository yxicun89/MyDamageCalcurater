# ADR-0313: 既定の計算モードをオンラインにし、取得したマスタを IndexedDB に保存してオフラインで使う(issue #210)

- 状態: 採用
- 日付: 2026-10-01
- レーン: Web
- 関連: issue #210、ADR-0301 §4(既定はオフライン。ここで変更)、ADR-0304(オンラインのマスタ取得口)、ADR-0002(実データを Git に入れない)、
  ADR-0307(pokedex フィクスチャ)、ADR-0300 §3(マスタの取得口)

## 背景

既定のオフラインは架空の例データ(「テストモン」5件程度)しか持たず、利用者が実際の種族・技・持ち物で計算するには
毎回オンラインへ切り替える必要があった。オンラインでマスタを取った後に API を遮断すると、全タブが使えない。
実データをビルドに同梱すると Git・イメージに実データが入る(ADR-0002 に反する)。

## 決定(ユーザー決定 2026-10-01。issue #210 の既定案 (b)+(c))

1. `DEFAULT_CALC_MODE` を `"online"` にする。保存済みの `localStorage` のモードは従来どおり尊重する(既存利用者の選択は変わらない)。
2. オンラインで取得したマスタを `MasterCacheStore`(`load`/`save`/`clear`。実装は IndexedDB、テストはメモリ fake)に保存する。
   - 保存するもの: 持ち物・性格(`load()` で全件取れる分)と、`resolveSpecies` で引いた種族・特性・技。タイプ相性表は `@typechart` から作れるので保存しない。
   - 書き込みの失敗・読み出しの失敗は握りつぶす(オンライン動作を妨げない。CLAUDE.md 絶対ルール5)。IndexedDB が使えない環境(private mode 等)は「常に空」として動く。
3. オフラインモードの取得口はキャッシュの読み出しのみ(オンラインを呼ばない)。capabilities は `speciesList/moves/effects` とも false のまま。
   種族の検索はキャッシュ済みの種族だけが対象。持ち物・特性の効果データは公開 API に無いので、オフラインでも「持ち物の候補比較」は選べない
   (従来の架空データではできたが、実データ相当では ADR-0304 A-1 と同じ制約)。
4. キャッシュが空(初回・未取得・破棄後)のオフラインは、架空データを出さず「オフラインで使うには、一度オンラインで開いてマスタを取得してください」旨の
   エラーにし、既存のマスタ読み込み失敗表示(role=alert・原因・再試行)に載せる(文言は `appText.masterCacheEmptyError`)。
5. キャッシュにスキーマ版(`MASTER_CACHE_SCHEMA_VERSION`)を持たせる。版違い・形が合わない(壊れた)データは破棄して空として扱い、次のオンライン取得で作り直す。
6. オンラインの失敗(API 遮断)は従来どおり「エラー+再試行」。キャッシュや架空データへ黙って落とさない(ADR-0301 §4 の自動フォールバック禁止を維持)。
7. 架空の例データ(`web/src/master/example/`)はテスト用に残し、`web/src/main.tsx` からは使わない(利用者の画面に出さない)。
8. E2E: 既定の `playwright.config.ts` も pokedex フィクスチャを起動して `/api/pokedex` を転送する(計算の `/api` は転送しない)。
   「一度オンラインで開いて種族を引く → API 遮断 → オフラインで計算」を確かめる。

## 実装で決めたこと(追記)

- 保存の形: 1レコード(`MasterCacheRecord`: `schemaVersion`・`items`・`natures`・`species`/`abilities`/`moves` はキー別の辞書)。
  IndexedDB は DB `pokecalc-master-cache`・ストア `master`・キー `record`。検証はレコードの形(配列・辞書)と版だけで、要素の中身までは見ない。
- 保存は読み書きを1本のキューに直列化し、取得口が結果を返す前に保存を終える(並行する解決の追記が互いを上書きしない。失敗は握りつぶす)。
  `resolveSpecies` の追記は、持ち物・性格が未保存(load 前)なら何もしない。
- オフラインの `searchSpecies` はキャッシュ済みの種族を日本語名の前方一致で返す(空白だけは空配列)。`resolveSpecies` は種族・特性・技をキャッシュから組み立て、無い種族は reject。
- 検索欄は種族のスロットの既定の入力になったため、攻守入れ替えで名前が追従するよう `SpeciesSearchField` に `selectedNameJa` を足した(CalcScreen のみ)。
  逆算は、種族の解決(非同期)を待つ間に打った観測が計算に反映されない古いクロージャの不具合を `latestObservationsRef` で直した。
- E2E: コンテナの nginx は /api を配らないので、`playwright.container.config.ts` は `container.spec.ts` だけを走らせる。CSP の下の WASM 計算は、
  /api/pokedex だけを pokedex フィクスチャ(`CONTAINER_POKEDEX_FIXTURE_PORT`)へ転送して一度オンラインで種族を引き、オフラインに切り替えて確かめる。
  k3d の E2E(`e2e-k3d/k3d.spec.ts`)のオフラインは、オンラインで引いた実マスタの種族をキャッシュから選んで計算する形に改めた。

## 未決・注意

- balance・speed・judge・team タブは従来どおり常に API を呼ぶ(モードを見ない)。ここでは変えない。
- キャッシュの有効期限・容量上限は設けない(マスタは版で変わるが、版違いはスキーマ版でだけ捨てる)。マスタ内容の更新検知は別 issue。
- 種族の保存は「解決した種族だけ」。一覧を持たないので、オフラインで引ける種族は一度オンラインで選んだものに限る。

## 影響

`web/src/master/cache/`(新規)、`web/src/main.tsx`、`web/src/app/calcMode.ts`、`web/src/i18n/ja.ts`、既存の単体・E2E の既定モード前提の更新。
