# ADR-0347: 構築画面の作り直し(G-05 / I-web-13d)

- 状態: 採用(2026-10-11)
- 関連: ADR-0339(方針)・ADR-0344(共通の部品)・ADR-0345/0346(計算・逆算)・ADR-0332(構築の作り直し)・ADR-0341(技ピッカー)

## 決めたこと

docs/design.md「画面ごとの方向」の構築の行を実装した。方針に無かった細部を決める。

1. **6 枠の格子は「欄への近道」**。埋まった枠は `PokemonCard`、空きは `Tile`(empty)で、押すとその枠の先頭の欄へフォーカスを移す。
   枠ごとの欄は従来どおり常に 6 枠分を出す(1 枠ずつの開閉にすると既存のテスト・E2E の前提 = 全枠が同時に見えるが崩れ、
   別のタスクになる)。キーボードは欄を Tab で順に辿れるので、タイルは `tabIndex=-1`(Tab の順に入れず、近道の二重の停止点を作らない。ポインタ・読み上げの操作は可能)。
   このため `Tile`・`PokemonCard` に任意の `tabIndex` を足した。
2. **技は select のまま**。`MovePicker` に替えると構築の既存テスト約 55 件と E2E の select 前提を付け替える必要があり、「最小の付け替え」を超える。後続 I-web-13d2 に分けた。性格は 5 択以上なので区切りボタンにせず select のまま(方針どおり)。
3. **SP は計算画面の `SpField` と同じ作り**: 文字の数値欄(不正な値を誤りとして出す仕様のまま)+ − / +。合計・残りは数値の文字で、バーは装飾(`aria-hidden`)。超過は danger 色。
4. **削除・上へ・下へ・外すはアイコンだけ**。読み上げ名は用語集の語のまま(「<名前>を削除」「N体目を上へ」等)。「開く」は見える文字を残す(WCAG 2.5.3)。破壊的操作の 2 段階の確認は変えない。
5. **空の一覧は大きいアイコン + 「まだ構築がありません」**(長い案内の文をやめた)。空の枠の案内(「ポケモンを選ぶと…」)は E2E が文を検証しているため今回は残した(空きタイルの「+」と並ぶ。後続で外せる)。

## 影響

新しい色の組は無い(枠線 = text.secondary / surface.card、数値の danger 色、brand.primary のバーは既存の検査の組)。常時動くアニメーションは無い。
既存テストの付け替えは、空の一覧の文を短くしたことによる 2 件(`teamRebuildText.test.ts`・`App.deviceData.test.tsx`)だけ。
