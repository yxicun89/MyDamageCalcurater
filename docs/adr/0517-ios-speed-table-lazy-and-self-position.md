# ADR-0517: iOS の素早さ表を遅延描画にし、自分の位置を表の中で示す(F-06)

- 状態: 採用
- 日付: 2026-10-04
- レーン: 素早さ(iOS)
- 関連: ADR-0503(素早さ比較画面)、docs/usability-round2.md F-06、ADR-0507(機能レジストリ)。Web 版(web/src/speed)は別 ADR
- 番号: iOS 帯 0500〜。open PR との衝突を避けて 0517 を使う

## 背景

ユーザー要望: 「自分の素早さを選んだものと、左の一覧を同じ高さにしたい」「一覧が長すぎるので、スクロールに合わせて周辺だけを表示したい」。
iOS の素早さ画面は縦 1 本の ScrollView で、上に「自分のポケモン」カード、下に表がある。iPhone の縦画面では、
表と自分のカードを横に並べる幅がない。表は全段を `VStack` で一度に生成しており、段数が多いと長い(ADR-0503 §6 は全段をアクセシビリティの木に出すため VStack にしていた)。

## 決定

### 1. 遅延描画

表の段は `LazyVStack`(SwiftUI 標準の仮想化)で描く。画面付近の段だけが生成される。独自の窓計算は持たない。
行の識別子(`speedTier-<speed>`・`speedBoundary`・`speedTierSelf-*`・`speedTierTie-*`)は変えない。ただし画面外の段は木に無い。

### 2. 自分の位置を「表の中」で示す(幅で並べない)

- 自分の行は、これまでどおり表の中の該当位置(自分と同じ実数値の段の強調、無ければ「ここに自分が入る」の境界線)。
  トリックルームの昇順でも `tableRows` が並びを済ませているので、同じ規則で動く。この「表の中で、速い段・同速・遅い段の境目に自分がいる」形が、
  縦画面での「同じ高さ」にあたる。横並びにはしない。
- 遅延描画で自分の行が画面外になるため、表の見出しの下に次を足す。
  - 位置の読み上げ(`speedTablePosition`)「全 N 段・自分は M 段目」(境界のときは「M 段目と M+1 段目の間」「1 段目の前」「N 段目の後」)。
    全段が木に無くなる代わりに、VoiceOver が総数と位置を得られる。
  - 自分の行が描かれている範囲の外にあるときだけ、ボタン「自分の位置へ(上/下)」(`speedJumpToSelf`)。押すと `ScrollViewProxy.scrollTo` で自分の行へ動かす(アニメーションしない。常時アニメ禁止)。
- 「描かれている範囲」は、行の onAppear/onDisappear で集めた添字。向き・読み上げ・自分の行の特定は純粋なロジック
  (`PokeCalcCore/SpeedTableNavigation`)に切り出し、XCTest で検証する。

### 3. 範囲

見た目(色・丸み・アイコン)は F-12 の領分。ここでは既存の部品(`SpeedPill`)だけを使う。契約・engine・他画面・共通のデザイン基盤は変えない。

## 結果・影響

- UI テスト: 末尾の境界線は表の下までスクロールしてから現れるので、既存の境界線のテストにスクロールを足した(期待は弱めていない)。遅延描画と「自分の位置へ」のテストを足した。
- 画面外の段は VoiceOver の巡回に出ないが、総数・位置は読み上げで補う。Dynamic Type は既存の Text のまま(行の高さは内容に従う)。
- 将来、表が非常に長くなったら、段のスクロール位置を覚える・絞り込み後に自分へ寄せる、を検討する。

## 追記(2026-10-04): AX5 の UI テストの操作を直した

`LargeTextLayoutUITests.testSpeedScreenResultAndTableNoHorizontalOverflowAtAX5` が #628 以降、`要素が見つからない: speedBoundary` で赤になった。原因は実装ではなくテストの操作: 遅延描画のため、表の段・境界線は画面外では描かれない(AX5 は入力欄が縦に長く、最初の画面に表が入らない)。実装の識別子・表示は欠けていない。
テストは、上限つきで遅い速度のスクロールを繰り返し、境界線・段・同速の段が一度ずつ描かれたことを確かめ、描かれたものごとに「横にはみ出さない」を検査する(上限までに見つからなければ失敗)。`swipeUp` の既定速度は勢いで 1 画面以上動き、同速の段を飛ばすため `swipeUp(velocity: .slow)` を使う。トリックルーム中は境界線が表の上側に出る。
