# ADR-0343: ポケモンを見せる各所に画像(無ければタイプ色エンブレム)を出す — G-06 Web

- 状態: 採用(2026-10-11。実装 PR で採用にした)
- 関連: docs/usability-round3.md G-06、ADR-0325(PokemonImage・manifest)、ADR-0808(配信)、ADR-0810(入手経路。データレーンの担当)、ADR-0002(画像は Git に載せない)、docs/design.md「見た目の作り直し方針(G-05)」、docs/ai-shared/decisions/2026-10-11-web-g06-pokemon-images.md

## 背景

画像の表示は計算のカード・素早さ表・構築の一覧だけだった。G-06 は「一覧・選択肢・計算・構築・素早さ表」に出すこと。画像は個人利用で Git に載せず、無いときはタイプ色エンブレムで成立する(AC-X)。

## 決定

1. 小さなポケモン表示の共通部品 `images/PokemonIcon.tsx`(`PokemonImage` の thumb + エンブレムの fallback)を足す。画像・エンブレムとも同じ 32px 角の枠(`.pokemon-icon`。寸法は CSS トークンの計算、`<img>` には width/height 属性)で、有無・読み込み失敗でレイアウトを動かさない。画像は装飾(alt 空・loading=lazy)で、名前は隣の文字が担う。エンブレムの色は最初のタイプ(`--type-<id>`。ID は英小文字・数字・ハイフンだけ許可)。タイプが分からない行(お気に入り・履歴)は中立色。
2. 出す場所(今回):
   - 種族検索の候補(`SpeciesSearchField` の各 option。1 行・名前は省略表示。キーボード操作・ARIA は変えない)
   - お気に入りの行(`individual.speciesKey`)・計算履歴の行(攻撃側・防御側の 2 つ)
   - 逆算の「自分」「相手」カードの見出し・構築の編集枠(legend)・タイプバランスのメンバー枠(legend)。種族が決まったときだけ
   - 既存: 計算のカード・素早さ表の行・構築一覧のアイコン列(ADR-0325)
3. 出さない場所と理由:
   - ネイティブ `<select>` の `<option>`(種族の一覧が select になるのは `speciesList` ありのマスタだけ。option に画像は置けない。選択後は上のカード・見出しの画像で示す)
   - 判定(非表示の画面)、調整(ec レーンの担当領域。G-05 の 13h で一緒に扱う)、タイプバランスの仮想敵の枠・結果表(結果表は名前のみの行。13f で扱う)
   - 入手(取り込み)はデータレーン(ADR-0810)。Web は manifest が来れば表示するだけ
4. API・engine・manifest の契約は変えない。CSS は 7KB gzip 前後で予算(30KB)内。常時動くアニメーションなし。

## 結果

画像が無い環境でもすべて従来どおり動き、エンブレムが並ぶ。検索候補は行が増えず 1 行のまま。
