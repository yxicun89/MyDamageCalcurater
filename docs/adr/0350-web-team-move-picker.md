# ADR-0350: 構築の技の欄を MovePicker にする(G-05 / I-web-13d2)

- 状態: 採用(2026-10-11)
- 関連: ADR-0341(技ピッカー・タイプ順)・ADR-0347(構築画面)・ADR-0308(下書きの保持)・ADR-0328(計算は攻撃技だけ)

## 決めたこと

1. 構築のメンバー編集の技 1〜4 枠の `<select>` を、計算・逆算と同じ共有 `MovePicker` に置き換えた。見える名前・トリガーの名前は従来どおり「技1」〜「技4」。
2. 候補は従来どおり「その種族の learnset を技の一覧で名前解決したもの + 現在値」。**変化技も含む**(計算の「攻撃技だけ」(ADR-0328)は構築に適用しない)。並びはタイプ順に変わる(ADR-0341。従来は learnset 順)。
3. `MovePicker` に 2 つの任意 prop を足した(計算・逆算は渡さないので挙動不変)。
   - `noneLabel`: 先頭に選べる「空にする」行(`data-move-id=""`。選ぶと `onChange("")`)を出し、空のトリガーにも同じ文言を見せる。検索で絞っている間は出さない。キーボード(矢印・Home/End・Enter)でも辿れる。構築では「(なし)」。
   - `disabledIds`: 選べない技の行を `aria-disabled` にし、押しても Enter でも選ばれない。構築で「他の枠が選んだ技はこの枠で選べない」(従来の option の disabled)を保つ。
4. マスタに無い現在値(別版で保存した構築)は、技 ID を名前にしたタイプ無し・変化技の代役の `Move` を足して壊さず開ける。タイプ無しの行・トリガーはタイプバッジを出さず、タイプ名も読まない。
5. 値の意味(moveIds・null の空き枠・保存時の詰め・下書き保持・G-02 の moveIds 正規化・SP/メガ)は変えない。

## テストの付け替え

構築用の枠単位の道具 `web/src/test/teamMovePicker.ts` を足し、select 前提の assertion を機械的に付け替えた(削除・弱体化なし)。
並びがタイプ順になったため、候補の並びを比べる 2 件は期待の並びを `orderMoves` / 集合 + 「(なし)が先頭」にした。

## iOS

iOS の構築編集の技の欄も同じ 1 行の行(タイプバッジ・技名・分類アイコン・威力)で選び、先頭に「(なし)」、他の枠で選んだ技は選べない、にそろえる(decisions/2026-10-11-web-g05-team-move-picker.md。ADR-0527)。
