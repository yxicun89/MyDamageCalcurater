# ADR-0351: 素早さ画面の作り直し(G-05 / I-web-13e)

- 状態: 採用(2026-10-11)
- 関連: ADR-0339(方針)・ADR-0344(共通の部品)・ADR-0345(SP の教訓)・ADR-0608(高さの定数)・ADR-0609(自分の周り)

## 決めたこと

docs/design.md「画面ごとの方向」の素早さの行を実装した。細部:

1. **領域の見出しは h2(アイコン + 短い名前)**。ポケモンカードの名前は h3。領域の名前(region)は従来のまま。
2. **自分はポケモンカード**(選んだときだけ。画像かエンブレム + 名前 + タイプバッジ)。ポケモンの選択は select のまま。
3. **入力の方法・調整・性格補正は `SegmentedControl`**、スカーフ・追い風・まひ・表の絞り込み・場の状態は `ToggleChip`。絞り込みの「最後の 1 つ」は `aria-disabled` を保つため `ToggleChip` に任意 prop `ariaDisabled` を足した。
4. **素早さ SP・ランクは `ui/Stepper` を使わず**、同じ見た目(`.ui-stepper`)の − / + と type=number の数値欄(ADR-0345 と同じ理由: 範囲外・空の入力を誤りとして出し送らない仕様を保つ)。範囲外の値からボタンを押すと範囲に収めた値になる。
5. **表の自分の段は枠 + 「自分」のバッジ(アイコン付き)**、同速はバッジ、境界と位置マーカーは brand.primary。読み上げの語(`selfTierLabel`)は残す。**行の高さ・1 行固定・余白・testid・仮想スクロールは不変**(ADR-0608)。狭い幅だけ位置マーカーの列を 7rem から 5rem にして、バッジが切れないようにした。
6. **自分の周りは小さなカード**(画像かエンブレム + 実数値の大きい数字 + 名前。自分のカードは「自分」のバッジ)。表のスクロール領域の外のまま。カードの画像のため `NeighborTierInput.entries` に任意の `pokemonId`・`types` を足した(並びの切り出しは見ない)。
7. 「自分」のバッジのアイコンは既存の `speed`(新しいアイコンは足さない)。

## 影響

新しい色の組は無い。API・engine・speed サービスの変更なし。

## 追記: 狭い幅での実測(同速の自分の段)

使い捨ての Playwright で、自分の段が同速(2 行・「自分」バッジ・「同速」バッジ・長い名前)のとき各 `.speed-tier` の scrollWidth と clientWidth を測った。高さは 64px(= 2×24 + 16。ADR-0608 の計算値)で変わらない。375px は 232 > 219 で切れていたため、480px 以下では表の「自分」バッジを文字なしのアイコンだけにし(読み上げは `selfTierLabel`)、段の gap と左右の余白を `--space-2` にした。直した後は 414px(258 = 258)・375px(219 = 219)・360px(204 = 204)で切れない。320px は 196 > 164 で「同速」が切れる(許容: これ未満の幅は対象外とした)。
