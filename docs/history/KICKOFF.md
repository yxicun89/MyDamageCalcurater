進め方:
1. CLAUDE.md を読み、「最初に読むもの」をすべて読む
2. git が未初期化なら初期化し、現状をコミットする
3. `./scripts/doctor.sh` を実行。不足する必須ツールは brew で入れる。入れられないもの(Xcode・ログインが必要なもの)は一覧にして報告し、M1 に不要なら先へ進む
4. `/phase M1` の手順で、docs/plan.md の M1 のタスクを上から順に最後まで進める
   - 各タスクはサブエージェント(quick-scanner → spec-writer → implementer → critic)で行う
   - 1タスク1コミット、plan.md を更新しながら進める
   - 詰まったタスクは「ブロッカー」に記録して、依存しない次のタスクへ進む
5. M1 の最後に `/verify` を実行し、`docs/verify-m1.md` に私が動作確認する手順を書いて止まる

私への質問は、CLAUDE.md の「人間の確認が必要なこと」に当たる場合だけにしてください。それ以外は要件・ADR・テスト戦略に沿って自分で判断し、判断したことは ADR に残してください。
