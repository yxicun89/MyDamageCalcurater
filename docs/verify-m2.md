# M2(保存・構築)の動作確認(Web)

上から順に実行する。各コマンドの下の「→」が成功の見え方。M1 の確認([verify-m1.md](verify-m1.md))が済んでいることが前提。

M2 の Web 機能は、構築ビルダー(P5-5a/5b)・よく計算する相手(P5-5c)・「この端末のデータを削除」(P5-5d)。
バックエンドは record-svc(計算イベント・よく計算する相手)と team-svc(構築)。
`make deploy-latest` は、calc・gateway・pokedex などに加えて NATS・TiDB・record・team も k3d に入れる
(`scripts/k3d-m2-deploy.sh`。ADR-0226)。TiDB が準備できなくても他のサービスの入れ替えは続くが、その場合は理由を表示して
非ゼロで終わる(§2 は M2 が揃ってから行う)。§1 の自動テスト(fake のバックエンド)は k3d が無くても行える。

## 1. 自動テスト(k3d 不要)

```sh
cd "$(git rev-parse --show-toplevel)"
make web-test
make web-e2e
make web-e2e-online
make web-e2e-container
```
→ すべて成功する。`web-e2e` の `team.spec.ts`(構築の追加→保存・SP 67 の拒否・タブ往復で下書きが残る)・
`deviceData.spec.ts`(両方の削除・片方失敗の再試行・キャンセル)、`web-e2e-online` の「よく計算する相手」(チップ→防御側・
record が 503 でも計算できる)が含まれる。

## 2. ブラウザで確認する(record・team が k3d で動いているとき)

`http://localhost:8080` を開く。開発者ツールの Network タブを開いておく。計算モードは「オンライン(API)」(既定)。

### 2-1. 構築ビルダー

1. 「構築」タブを開く → 「保存した構築」の一覧(空の案内)と「新しい構築」の作成フォームが出る。
2. 「構築名」を入れて「作成」を押す → 一覧に出る(`POST /api/team/teams` が 201)。
3. 「「名前」のメンバーを編集」を押す → メンバー編集が開く。「メンバーを追加」で種族を選び、技を4つまで・持ち物・特性・性格・テラスタイプを選ぶ。
4. SP の6欄に 32 と合計 66 まで入れる → 合計と残りが出て保存できる。1つに 33、または合計 67 にする → エラーが出て保存できない。
5. 「メンバーを保存」を押す → `PUT /api/team/teams/{id}` が 200 で、「保存しました」が出る。ページを再読み込みして開き直す → 同じ内容が残っている。
6. 別のタブへ移って「構築」に戻る → 編集中の(未保存の)下書きが残っている。
7. 「「名前」を削除」→「「名前」の削除を確定」の順に押す → 一覧から消える(2段階。取り消せない旨が出る)。

### 2-2. よく計算する相手

1. 「計算」タブで、攻撃側と防御側を選ぶ操作を何度か(同じ防御側で)繰り返す。
2. ページを再読み込みする → 防御側の欄の下に「よく計算する相手」のチップが出る(`GET /api/record/frequent-opponents` が 200)。
3. チップを押す → 防御側にその種族が入り、結果が出る。
4. record-svc を止める(`kubectl -n pokecalc scale deploy/record --replicas=0`)→ 再読み込みしてもチップが出ないだけで、計算は成功し、エラー表示は出ない。
   確認後に `--replicas=1` に戻す。

### 2-3. この端末のデータを削除

1. ページ下部の「このアプリについて」を押す → 「データの扱い」に説明と「この端末のデータを削除」が出る。
2. 「この端末のデータを削除」を押す → 確認ダイアログが出て、初期フォーカスは「キャンセル」。Esc またはキャンセルで閉じ、何も通信しない。
3. もう一度押して「削除する」を押す → 「削除しました。」が出る(`DELETE /api/record/device-data`・`DELETE /api/team/device-data` が 200)。
4. 「計算に戻る」→「構築」タブ → 構築の一覧が空になっている。「よく計算する相手」のチップも出ない。計算は引き続き使える。
5. team-svc を止めて 2〜3 を繰り返す → 失敗の文言と「もう一度削除する」が出る(成功とは表示されない)。戻して再試行 → 完了する。
