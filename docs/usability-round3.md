# 使用感フィードバック第 3 回(2026-10-11)の対応表

第 2 回([usability-round2.md](usability-round2.md))の反映後にユーザーが実際に動かして出た感想。レーンをまたぐ。進捗はこの表の「状態」を更新する。

## ユーザーの決定(この回)

- 技の並びは**タイプ順だけ**にする。並びの切り替え(五十音・習得順・タイプ順)は廃止し、選ぶ操作もなくす。
- Showdown 形式の取り込みは**廃止**する(使いにくいので、入口ごと外す)。
- ポケモンの画像・アイコンを使う。商用公開の予定はない(個人利用)。ただし画像そのものは引き続き Git に入れない(ADR-0002・ADR-0808)。
- 動作確認の手順書は **1 本に統一**する。Web(ブラウザ)と iOS(Xcode)を両方含める。
