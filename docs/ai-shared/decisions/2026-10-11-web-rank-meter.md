## 2026-10-11: 能力ランクの入力を 13 段のメーターにした(Web 実装 / ADR-0357。iOS・ec レーンへ)
Decision: ランク(-6〜+6)の入力を、数字ではなく 13 段のメーターにする。iOS も同じ段数・同じ色の意味・同じ読み上げにそろえる。
- 段: 左 6 = 下降、中央 = 0(常に見える太い目印)、右 6 = 上昇。範囲外は作れない。
- 色(トークン名): 上昇 = `brand.primary`(空色系)、下降 = `warning`(橙系)、0 の目印 = `text.primary`、段の枠 = `text.secondary`。赤は弱点と紛れるので使わない。値は符号付き(`+2` / `-3` / `±0`)の文字でも出し、色だけに頼らない。
- 操作: タップ / ドラッグで最も近い段、− / + ボタン(名前は「<欄の名前>を上げる / 下げる」)、矢印キー(Web)。iOS はドラッグ + − / + と `accessibilityAdjustableAction`(増減)。
- 読み上げ: スライダー(iOS は adjustable)の値は「攻撃 +2」(ステータス名 + 符号付きの数、0 は「±0」)。ステータス名は 攻撃・防御・特攻・特防・素早さ。
- 適用: ダメージ計算の「詳細」(攻撃側・防御側)、素早さ(自分)、判定(5 欄)。
- 実装: `web/src/ui/RankMeter.tsx`、`web/src/styles/components.css`(`.ui-rank*`)、`docs/design.md`「共通の部品」、`docs/glossary.md`(上げる / 下げる)。
Reason: バトンタッチ・つるぎのまい等で「いまの段階」を手で入れる用途。数字より位置で見る(ユーザー要望ラウンド 4)。
Impact: iOS の計算・素早さ・判定のランク入力。API・engine の変更なし。
