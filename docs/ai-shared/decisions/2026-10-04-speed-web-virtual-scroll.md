## 2026-10-04: 素早さ表(Web)を仮想スクロールにし、右の位置マーカーを左の該当行と同じ高さに揃える(素早さレーン。ADR-0608。F-06 の Web 分)
Decision: 左の素早さ表は、自前の windowing(`web/src/speed/speedWindow.ts`)で見えている行の周辺だけを DOM に出す。依存は足さない。段の高さは同速の行数だけで決まる(1行 24px 固定・折り返さない)ので、全段の offset を先に計算できる。自分の位置(同速の段か境界の行)を表の1行として同じ座標系に入れ、右の位置マーカーを「その行の offset - スクロール量」の高さに置く(画面外では端に張り付き、「自分の位置へ移動」ボタンで中央へ)。a11y は ul/li を保ち、各段に aria-setsize・aria-posinset、スクロール領域は tabindex=0 の名前付き group。
Reason: 数百段の全描画が長い・自分の位置が分かりにくいというユーザー要望(使用感フィードバック第2回 原文 9・10)。
Impact:
- iOS: F-06 の iOS 分を別 PR で。Web と同じく「自分の位置が表のどこか分かる」「画面外の行は描画しない(List/LazyVStack が既にその挙動)」を満たせばよく、見た目の実装は自由。
- Web の他レーン(F-12 のデザイン基盤): 触ったのは `web/src/speed/` と `web/src/i18n/speed.ts` のみ。素早さ画面の行の見た目を変えるときは、行の高さ(speedWindow.ts の定数)を保つこと。
