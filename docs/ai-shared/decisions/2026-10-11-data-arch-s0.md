## 2026-10-11: ヘキサゴナル採用の S0(規約・ADR・検査の骨組み。ADR-0811)
Decision: Go の全サービスに `internal/{domain,app,adapters}` の形(adapters → app → domain の一方向)を採用する。`tools/archcheck` を `make lint` に組み込んだ。形をそろえたサービスは依存の向き(内側が外側を取り込まないこと)を検査し、未移行の一覧(`tools/archcheck/archcheck.go` の `unmigrated`。初版は全 8 サービス)のサービスは通す。一覧に無いのに形がそろっていないサービスは失敗する。
Reason: 人間があとで構造を確認しやすくするため(ユーザー決定 2026-10-11。方式 A・§8 の Q2〜Q10 は推奨どおり)。計画は docs/plan/architecture-adoption.md。
Impact: 全レーンの以後の PR は `make lint` の archcheck を通る。既存のサービスは一覧にある間は何も変わらない。新しいサービス・新しい機能(コンボ計算など)は最初から `internal/{domain,app,adapters}` をそろえる(中身の無いフォルダも `doc.go`)。移行は 1 サービス = 1 PR = そのサービスのレーン(judge → calc → record → pokedex の順。着手前にこのディレクトリへ 1 件足す)。移行の PR は一覧から自分のサービスを 1 行消す。
