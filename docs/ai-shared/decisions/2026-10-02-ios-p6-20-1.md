## 2026-10-02: P6-20 構築の Showdown 風テキストは日本語名・非互換(iOS レーン → Web・判定レーンへ。ADR-0506)
Decision: (1) 構築のインポート/エクスポートは**日本語名の Showdown 風テキスト**。実 Showdown とは互換にしない(英語名が iOS にも API にも無く、
「nameEn は含めない」は覆さない)。実 Showdown のテキストを貼ると名前が解決できず「取り込めなかった行」に出る(黙って捨てない)。
(2) 書式(Web の参照実装がリモートに無いので iOS で確定。Web が揃えるなら同じ文言): 先頭行 `名前 @ 持ち物`(ニックネームは `ニック (名前)`)/
`Ability: 特性` / `Tera Type: タイプ` / `SP: 32 Atk / 20 Spe`(略称 HP/Atk/Def/SpA/SpD/Spe、0 は省く)/ `Nature: 性格` / `- 技名`(4つまで)。
メンバーは空行区切り。キーワードは英語、値は日本語名。取り込みは Ability 以降の順不同。SP は 0〜32・合計66(EV ではない)。`EVs:`・`IVs:` は
取り込めない行(換算しない)。(3) 解釈できない・解決できない行は行番号・内容・理由で一覧にし、取り込めた分だけ追加するかを選ばせる(既定案。全か無かにしない。
人間レビューで変えてよい)。取り込みは保存を伴わない。(4) 名前の戦略は差し替え可能な型(`ShowdownNaming`)で、API に `nameEn`/`showdownId` が足されたら
英語名にも広げられる。
Reason: requirements.md §2 の必須。英語名データが無い範囲で、利用者が自分の構築を書き出し・貼り付けで移せる最小の形にした。
Impact: Web レーンは同じ書式にするか、違う判断を DECISIONS.md に書く。判定レーンへ: 書式は構築の `TeamMember` の項目だけを写す(判定・計算ロジックは無関係)。
API・Generated は不変。文言の確定表は ADR-0501「P6-20」3章。
