## 2026-10-11: 調整画面の作り直し(G-05 / I-web-13h / ADR-0353。iOS・ec レーンへ)
Decision: Web の調整画面は見た目だけ次の構造にした(ロジック・API・語は不変)。iOS も同じ構造に追う(部品の対応は docs/design.md「iOS の追い方(G-05)」)。
- 自分・相手(相手が要るモード)は選ぶとポケモンカード(画像かエンブレム・名前・タイプバッジ・持ち物の印)。メガ種族はストーン固定のままで、持ち物の印にもストーン名を出す。
- 固定する能力ポイントと上限は − / + 付き(数値欄は直接打てる。範囲外は従来どおり「調整する」で誤りとして出し、送らない)。
- 目標: 追加は「+」の空きタイル(「目標を追加」。上限は無効 + 理由)。カードは種類のアイコン(素早さ=速度、耐える=盾、倒す=計算)と、選んだ相手の小さなポケモンカード。
- 結果: 振り方(能力ポイント)の文の下に能力ごとの横棒(幅 = 能力ポイント / 32、装飾)と大きい数字。結論(目標を満たす/満たさない・倒せる/耐えられる)は成功/失敗のアイコン + 従来の文。
Reason: 方針(文で説明しない・色だけに頼らない)を調整画面に適用した Web の結果を iOS が追うため。
Impact: iOS 調整画面(追う側が合わせる)。API・engine・calc サービスの変更なし。語の追加・変更なし。
