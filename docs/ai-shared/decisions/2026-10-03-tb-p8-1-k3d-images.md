Decision: k3d への画像配線は、クラスタを作り直さず `make images-k3d` が dist をノードコンテナへ `docker cp` し、gateway の local overlay(Component local/api)だけが hostPath(読み取り専用・DirectoryOrCreate)で `GATEWAY_IMAGES_DIR` に見せる。base・cloud overlay には足さない。
Reason: `make up` の k3d.yaml(volume mount)を変えると既存クラスタを壊す。gateway イメージは FROM scratch で kubectl cp できず、Argo CD の selfHeal が set env を戻すため。
Notes: 置き換えはディレクトリを作り直さず中身だけ消す(rm -rf すると動作中の Pod の bind mount が古い実体を指して 404 になる。実機で確認)。入口(8080)は未知パスを HTML で返すので確認は Content-Type も見る。deploy-latest は画像配置の失敗を無視する。ADR-0807 追記・docs/runbooks/images.md §3。
