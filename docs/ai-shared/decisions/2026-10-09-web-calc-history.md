## 2026-10-09: Web の計算履歴の一覧(お気に入りの画面の第2の節。ADR-0338。iOS レーンへ)
Decision: iOS の「お気に入り・履歴」も次の語・挙動に揃える。
- 節の名前「計算履歴」、一覧の名前「計算履歴の一覧」、続きは「もっと見る」(`nextCursor` が null でない間だけ。cursor は加工せずそのまま渡す)、各行のボタンは「この計算を使う」。
- 行の見出しは「攻撃側 → 防御側」(Web は key のまま。名前の解決をする側は同じ並びで)。技・「min〜max%」・読みやすい日時を添える。生の ISO 文字列は出さない。
- 続きの取得が 400(古い cursor)なら、cursor なしで先頭から1回だけ読み直す。読み直しも失敗したらエラー表示で止める(繰り返さない)。
- 失敗は節の中だけに閉じ込める(見出し「計算履歴を読み込めませんでした」+サーバーの message)。お気に入りの一覧・計算画面は塞がない。続きの失敗は読み込み済みの行と「もっと見る」を残す。
- 行の calc は、お気に入りの「計算に使う」と同じ経路で復元する(サーバーへ保存しない)。ポーリングしない。
Reason: ADR-0230 の依頼。Web と iOS で同じ体験にする。
Impact: iOS レーン(履歴一覧の接続・「契約待ち」注記の解除)。API 契約の変更なし。
