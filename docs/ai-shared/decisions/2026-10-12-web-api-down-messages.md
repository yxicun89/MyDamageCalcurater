## 2026-10-12: balance / speed / judge が使えないときの文言に原因の目安を足した(Web。ec ラウンド 4 (3))
Decision: サーバーに届かない・上流が起動していないときの Web の文言を、「接続できません」だけでなく原因の目安が分かる形にした。
- 通信できない・応答が読めない(`balance_unavailable` / `speed_unavailable` / `judge_unavailable`): 「…に接続できません。起動中か、通信が切れている可能性があります。しばらくしてからもう一度お試しください」
- gateway が上流に届かない(サーバーの Error 封筒 `upstream_unavailable`): 「…のサーバーが起動中か、一時的に使えません。しばらくしてからもう一度お試しください」。balance には今まで対応する文言が無く、汎用の失敗文言になっていた。
Reason: Pod の起動失敗でユーザーに見える文言が原因を示さなかったため。サーバー側の原因の修正は tb-0b / speed-40。
Impact: Web の i18n のみ(API・契約の変更なし)。iOS も同じ分類(通信不可 / 上流が起動中)で文言をそろえると良い。
