## 2026-10-11: 技の選択肢を 1 行にし、並びをタイプ順だけにする(Web。G-01 / ADR-0341。iOS レーンへ)
Decision: Web の計算・逆算の技欄を `<select>` から技ピッカー(検索つき listbox)にした。1 行は「タイプバッジ + 技名」が主、分類(ぶつり/とくしゅ)は小さなアイコン、威力は副。
並びは**タイプ順だけ**(タイプ表の並びで群にし、群の中は五十音順・同順位は技 ID 昇順・表に無いタイプは最後)。習得順・五十音順・切り替えのチップ・並びの保存は廃止(ADR-0335 を一部置き換え)。
既定の技の自動選択は learnset の最初のダメージ技のまま。読み上げ名は「技名、タイプ名、分類、威力 N」。分類アイコンの読み上げ名は ぶつり/とくしゅ/へんか(用語集の語)。
Reason: ユーザー要望(docs/usability-round3.md G-01)。`<select>` では絵と 1 行の構成ができない。
Impact: iOS は ADR-0527(PR #673)で同じ決定を実装済みのため追加作業なし。iOS の `MoveSort.byType` の「群の中は五十音順・同順位は技 ID」は Web の `orderMoves` と同じ規則であることだけ確認する。
  分類アイコンの意味(放射状の衝撃/同心の波/半分の円 と SF Symbols の対応)は `PopSymbol` と Web の `Icon` でそろえる。API・engine・マスタの変更なし。
