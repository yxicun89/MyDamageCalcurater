## 2026-10-11: 逆算画面の作り直し(G-05 / I-web-13c / ADR-0346。iOS レーンへ)
Decision: Web の逆算画面は次の構造・語にした。iOS の逆算画面も同じ構造に追う(部品の対応は docs/design.md「iOS の追い方(G-05)」)。
- 自分・相手: 見出し(「自分」「相手」)の下に画像かエンブレム + 名前 + タイプバッジ(+ 自分だけ持ち物の印。メガ種族は固定のストーン名)のカード。その下に選ぶ欄。
- ダメージの側(与えたダメージ/受けたダメージ)・各ダメージの単位(% / HP)は区切りボタン(`Picker(.segmented)`)。自分の調整はチップ。単位の 1 行(「相手の HP が減った割合(%)」等)は欄の下に残す。
- 候補のカード: 1 行目に型の名前(補正なし/B上昇)・目安の名前のバッジ・「ほぼ合う候補」のバッジ(警告色の枠)、右に予測%の大きい数字、次に予測%の上限のバー(装飾)、下に SP の範囲(全候補が不一致のときは「参考」バッジ)・持ち物・特性を小さく。未対応の印は従来どおり。
- 種族検索欄(オンライン時)の補足の文「日本語名の先頭の文字を入力すると候補が出ます」は常時出さず、「説明」ボタンの奥(計算・タイプバランス・構築の検索欄も同じ)。
- 上の検索欄の変更は共通部品なので、計算・タイプバランス・構築の検索欄にも同じく効く(iOS も同じ画面で同様に補足を奥へ)。
Reason: 方針(文で説明しない)を逆算画面に適用した Web の結果を、iOS が同じ見た目・語で追うため。
Impact: iOS レーン(逆算画面の作り直し時)。API・engine の変更なし。語の追加なし。
