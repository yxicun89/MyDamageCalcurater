## 2026-10-11: ポケモン画像を各所に出す(Web。G-06 / ADR-0343。iOS レーンへ)
Decision: Web は小さな共通部品 `PokemonIcon`(32pt 角の枠・画像があれば表示、無い・読めないときはタイプ色の円のエンブレム)を、種族検索の候補、お気に入りの行、計算履歴の行(攻撃側・防御側)、逆算・構築編集・タイプバランスのメンバー枠の見出しに足した(既存: 計算カード・素早さ表・構築一覧)。
fallback の規則: manifest(ADR-0808)にキーが無い・取れない・読み込み失敗は、エラーにせずタイプ色のエンブレム。同じ寸法の枠で有無によるレイアウトの動きを出さない。画像は装飾(読み上げ対象外)で、名前は隣の文字。タイプが分からない行(お気に入り・履歴は speciesKey だけ)は中立色。
Reason: docs/usability-round3.md G-06。画像は個人利用で Git に載せない(ADR-0002・0808・0810)。
Impact: iOS レーンは同じ場所(候補の行・お気に入り・履歴・各枠の見出し)に、既存の画像部品とエンブレムの fallback で追従する。判定(非表示)・調整は対象外。画像の入手経路はデータレーン(ADR-0810)。
