## 2026-10-11: 素早さ画面の作り直し(G-05 / I-web-13e / ADR-0351。iOS・speed レーンへ)
Decision: Web の素早さ画面は次の構造・語にした。iOS の素早さ画面も同じ構造に追う(部品の対応は docs/design.md「iOS の追い方(G-05)」)。
- 領域の見出し(素早さの表・自分のポケモン)はアイコン(素早さ)+ 名前。自分を選ぶとポケモンカード(画像かエンブレム・名前・タイプバッジ)。
- 入力の方法・調整・性格補正は区切りボタン、スカーフ・追い風・まひ・表の絞り込み・場の状態はチップ。素早さ SP・ランクは − / + 付き(範囲外は誤りとして出し送らない仕様は不変)。
- 表の自分の段は枠 + 「自分」のバッジ(アイコン付き)、同速はバッジ。境界・位置マーカーは主色。行の高さ(ADR-0608: 1 行 24 / 段の余白 16 / 隙間 8 / 境界 32)は不変。
- 自分の周りは小さなカード(画像かエンブレム + 実数値の大きい数字 + 名前)。自分のカードに「自分」のバッジ。文言の追加・変更なし。
Reason: 方針(文で説明しない)を素早さ画面に適用した Web の結果を、iOS が同じ見た目・語で追うため。
Impact: iOS 素早さ画面(speed レーンが追う)。API・engine の変更なし。語の追加なし。
