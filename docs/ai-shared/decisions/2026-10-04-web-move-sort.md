## 2026-10-04: 技の選択肢の並び(Web〈web-move-sort-f02〉から iOS へ)
Decision: Web の計算・逆算の技欄に並びの切り替えを足した(ADR-0335)。iOS も同じ語・同じ規則に揃える。
- 並びの種類と既定: 習得順(既定)・五十音順・タイプ順。語は「習得順」「五十音順」「タイプ順」。UI 名は「技の並び」。
- 五十音順: 日本語照合(`localizedStandardCompare` ではなく、ひらがな/カタカナ・濁点を同じ字として比べる照合。Foundation の
  `Locale(identifier: "ja")` で `compare(_:options:[.widthInsensitive, .caseInsensitive]:locale:)` 相当)。濁点だけの違いは同じ字の中で後。
  長音「ー」は照合器の扱いに従う。同順位は技 ID の昇順。
- タイプ順: マスタのタイプ表の並びで群にし、群の中は五十音順。技のあるタイプだけ。タイプ表に無いタイプは最後(ID の昇順)。
  見出しはタイプ名(Picker の Section)。習得順・五十音順は見出しなしの平らな並び。
- 保存: UserDefaults の1キー(`pokecalc.moveSort` 相当)。不正値は既定。計算と逆算で共有する。
- 既定の技の自動選択は learnset の最初のダメージ技のまま(五十音順でも先頭にしない)。選択中の技は並びを変えても保つ。
  お気に入りの技を戻せなかったときの未選択の選択肢は、どの並びでも先頭(見出しの外)。並びを変えるだけでは再計算しない。
Reason: 利用者の要望(原文6)。覚える技が多い種族で目当ての技を探しやすくする。Web と iOS で同じ語・規則にして挙動を揃える。
Impact: iOS の技 Picker に並びの切り替え(習得順・五十音順・タイプ順)を足す。engine・API・マスタの契約は変わらない。
