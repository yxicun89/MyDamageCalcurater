## 2026-10-11: 構築の技の欄を 1 行の行にする(G-05 / I-web-13d2 / ADR-0350。iOS レーンへ)
Decision: Web の構築編集の技 1〜4 は、計算・逆算と同じ技ピッカー(1 行 = タイプバッジ・技名・分類アイコン・威力)で選ぶ。iOS の構築編集(ADR-0527 の技の行)も同じにそろえる。
- 候補はその種族の覚える技すべて(変化技も含む。計算の攻撃技だけの絞りは構築に適用しない)。並びはタイプ順(マスタのタイプ表の並び → 群の中は五十音)。
- 先頭に「(なし)」の行(選ぶと枠が空く)。空の枠は「(なし)」と表示。
- 他の枠で選んだ技は、この枠では選べない(行は薄く、押せない)。自分の枠の技は選べる。
- マスタに無い技 ID を持つ構築は、技名を ID のまま・バッジ無しで開ける(壊さない)。
- 読み上げ名は従来どおり「技1」〜「技4」。保存値(moveIds・空き枠の詰め)は不変。
Reason: 構築画面の見た目を計算・逆算とそろえ、技の選択を iOS と Web で同じ体験にするため。
Impact: iOS レーン(構築編集の技の欄)。API・engine の変更なし。
