## 2026-10-03: ローカルの待ち受け範囲(issue #302。データレーン → 運用)
Decision: ユーザー決定 2026-10-03「既定案で OK」。
- Ingress(8080)は**全インターフェースのまま**にする(iPhone 実機が Mac の LAN IP で届く必要があるため)。
- k8s API は 127.0.0.1 に限定済み(#461)。
- gateway の `/metrics` を公開入口から外すのは issue #216(API レーン)で行う。
Reason: 認証なし・自分用の構成で、LAN からの到達は iPhone 実機の確認(M3)に必要。露出を減らすのは、実機が不要な k8s API と、公開入口に出す必要のない `/metrics` から。
Impact: 設定の変更は無し(記録のみ)。issue #302 は閉じてよい(残りは #216)。
