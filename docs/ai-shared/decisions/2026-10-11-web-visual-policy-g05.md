## 2026-10-11: 見た目の作り直し方針(文で説明しない UI。G-05 / ADR-0339。iOS レーンへ)
Decision: Web と iOS は docs/design.md「見た目の作り直し方針(G-05)」に従って画面を作り直す。要点:
- 画面の文字は「名前・短いラベル・数値と結果・状態の一言」だけ。文はエラー・空の状態・取り消せない確認・単位の説明・このアプリについてに限る。補足は 1 節 1 行まで。説明は「説明」ボタンで 1 段だけ開く。
- アイコン + 短いラベルが基本。アイコンだけのボタンは読み上げ用の名前(用語集の語)必須。技の分類(ぶつり・とくしゅ・へんか)はアイコン、タイプはタイプバッジ(狭い所はタイプ色の丸 + 名前)。公式アイコンは使わない。画像が無ければエンブレム。
- 部品の対応: 区切りボタン = `Picker(.segmented)`、増減ボタン = `Stepper`、ピッカー = `.sheet` + `presentationDetents` + `.searchable`、空の状態 = `ContentUnavailableView`、タイル = `LazyVGrid` + `popCard`、触覚 = `.sensoryFeedback`。
- 動きは操作時だけ。視差効果を減らすで 0。常時の動き(回る読み込みを含む)は置かない。
Reason: ユーザー要望(docs/usability-round3.md G-05)。Web が方針を先に決め、iOS は同じ方針で追う。
Impact: iOS レーン(画面ごとの作り直し。技の分類の SF Symbols か自作シンボルの選定)。API・engine・トークンの値の変更なし。新しいアイコン名を足したら `PopSymbol` に同じ意味を割り当てる。
