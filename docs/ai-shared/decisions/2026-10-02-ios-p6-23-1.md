## 2026-10-02: iOS 種族ピッカーに「よく使う相手」を出す(iOS レーン → Web レーンへ。P6-23・ADR-0501「P6-23」)
Decision: iOS は `GET /api/record/frequent-opponents`(limit 10)を、**計算の防御側・逆算の相手のピッカーの空クエリのときだけ**、一覧の先頭に
「よく使う相手」として出す(攻撃側・自分・構築メンバーには出さない)。名前・タイプは `species(key:)` で1件ずつ(同時4件まで)引き、
解決できない key は黙って省く。取得はシートを開くたびに1回。失敗・空は何も出さず、検索と計算を塞がない(絶対ルール5)。
`PokeCalcService` とは別のプロトコルで持つ。
Reason: 頻度は相手(防御側)の記録なので、相手を選ぶ場所だけに出すと意味が混ざらない。補助機能なので失敗を表に出さない。
Impact: Web は `frequent-opponents` を使っていない。Web でも出すなら、上の規則(出す場所・空クエリのみ・limit・未解決は省く・失敗は黙る・
開くたびに再取得)に揃えるか、違う判断を DECISIONS.md に書く。API の変更はない(openapi・Generated は不変)。
