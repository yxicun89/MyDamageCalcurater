## 2026-10-11: お気に入り・計算履歴の作り直し(G-05 / I-web-13g / ADR-0348。iOS レーンへ)
Decision: Web のお気に入り・計算履歴は次の構造・語にした。iOS も同じ構造に追う(部品の対応は docs/design.md「iOS の追い方(G-05)」)。
- 見出しはアイコン + 名前(お気に入り = 星、計算履歴 = 時計)。
- お気に入りの行: 画像かエンブレム + 名前(旧お気に入りは「攻撃側だけ…」のバッジ)。「使う」(電卓アイコン + 文字)と「削除」(ごみ箱アイコン + 文字)。読み上げ名は従来の「「X」を計算に使う」「「X」を削除」のまま。行全体を押すと使う(ボタンは 1 つ)。削除は 2 段階の確認のまま。
- 計算履歴の行: 攻撃側 → 防御側のアイコン、「攻撃側 → 防御側」の名前、技、結果の % を大きい数字で、最大 % のバー(100 で止まる。装飾)、日付は小さい補足、「使う」。「もっと見る」は下向きの山のアイコン付き。
- 空の状態: 大きいアイコン + 「お気に入りはまだありません」「計算履歴はまだありません」(旧: 追加・計算のやり方の 2 文目を外した)。「計算へ」のボタンは Web では未実装(後続候補)。
- 読み込み中・失敗はアイコン + 一言の案内。失敗は各節の中に閉じる(計算には影響しない)。
Reason: 方針(文で説明しない)をお気に入り・計算履歴に適用した Web の結果を、iOS が同じ見た目・語で追うため。
Impact: iOS レーン(お気に入り・履歴画面の作り直し時)。API・engine の変更なし。新しい語は「使う」「削除」(見える短い文字)。
