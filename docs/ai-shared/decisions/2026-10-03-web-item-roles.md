## 2026-10-03: Web の持ち物欄を役割で絞り、メガストーンを「{基本種名}のメガストーン」と表示する(Web レーン → iOS レーン。ADR-0326)
Decision: 持ち物の選択肢は共通関数 `itemsForRole` で作る(計算の攻撃側 attacker・防御側 defender、逆算の自分は観測した側の反対・相手の候補は相手の側、判定・調整は either、構築の編集は any)。
`roles` が無い持ち物(古いサーバー・例データ)は絞らない。メガストーンは選択肢に出さず、固定中は「{基本種名}のメガストーン」(基本種名が無ければ「メガストーン」)と表示し、ストーンの名前は出さない。
攻守入れ替え・観測した側の切り替えで合わなくなった持ち物は「持ち物なし」に戻して通知する。
Reason: ユーザーの実使用の不具合報告(メガストーンの英語表記・攻撃側にオボンのみ等の意味のない持ち物)。PR #579(ADR-0175)でサーバーが `roles`・`isMegaStone`・`baseSpeciesNameJa` を返すようになった。
Impact:
- iOS レーン: 同じ語(「{基本種名}のメガストーン」「メガストーン」・外した通知の文言)と同じ絞り込みにそろえる(docs/mega-evolution-spec.md §4-3)。
- Web: マスタのキャッシュ版を 2→3 に上げた(古いキャッシュは破棄され、次のオンライン取得で作り直す)。
