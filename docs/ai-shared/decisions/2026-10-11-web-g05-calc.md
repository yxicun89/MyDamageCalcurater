## 2026-10-11: 計算画面の作り直し(G-05 / I-web-13b / ADR-0345。iOS レーンへ)
Decision: Web の計算画面は次の構造・語にした。iOS の計算画面も同じ構造に追う(部品の対応は docs/design.md「iOS の追い方(G-05)」)。
- 攻撃側・防御側: 見出し(「攻撃側」「防御側」)の下に画像かエンブレム + 名前 + タイプの丸/バッジ + 持ち物の印のカード。メガ種族は固定のメガストーンの名前を印にする。その下に選ぶ欄(ポケモン・持ち物・特性)。
- 攻撃・特攻のブロック: プリセットのチップ(選択中は塗り + チェック)、SP の数値欄 + 「<攻撃のSP>を減らす/増やす」の − / + ボタン(0〜32 で止まる。欄の不正な値は誤りとして出す仕様のまま)、性格補正は 3 択の区切りボタン(`Picker(.segmented)`。選べない選択肢は無効 + 理由の 1 行)。
- 結果の行: 1 行目に「ダメージ幅の大きい数字」と「確定数のバッジ(塗り)」、2 行目にバー、最後に調整・持ち物・特性を小さく。技の相性(ばつぐん等)は枠だけのバッジ。
- 条件(「詳細」の中): 急所・やけど・天候・フィールド・防御側の壁はチップ、ランクは − / + のボタン(名前は「攻撃側のランクを上げる」等のまま)。「持ち物の候補も比較」もチップ。
- 「対戦の状態」: 防御側の残りHPの 2 文の説明は「説明」ボタン(`.popover`)の奥。単位・「空なら満タン」の 1 行は欄の下に残す。開閉ボタンは下向きの山のアイコン + 名前。
Reason: 方針(文で説明しない)を計算画面に適用した Web の結果を、iOS が同じ見た目・語で追うため。
Impact: iOS レーン(計算画面の作り直し時)。API・engine の変更なし。語の追加なし(既存の語と「共通の部品の語」だけ)。
