# 用語集(画面で使う言葉の正)

画面に出す言葉の正です(F-13、ADR-0337)。Web の文言資源(`web/src/i18n/*.ts`)と iOS の Text は、ここに書いた同じ語を使います。
新しい画面・文言を足すときは、先にこの用語集を見て、ここにある語を使います。新しい語が要るときは、この表に足してから使います。

## 言い換えの基準

- **ポケモン対戦でふつうに使う語・ゲーム内の語は変えない**(下の「変えない語」)。対戦をする人にはそのほうが伝わります。
- **アプリの内部の仕組みや、開発者向けの語だけをやさしい言葉にする**(下の「言い換える語」)。初めて使う人が意味を想像できない語です。
- 文の形も機械的にしない(「メガシンカ: 〜」のような見出し+コロンの書き方をせず、ふつうの文にする)。
- 文言資源のキー名は変えず、値(文言)だけを変える(参照するコードを壊さないため)。

## 変えない語

対戦の標準の用語・ゲーム内の用語です。言い換えません。検査(`web/src/i18n/glossary.test.ts`)は、
これらの語がどれかの画面の文言に残っていることを確かめます(言い換えすぎの防止)。

| 語 | メモ |
|---|---|
| `確定` | 確定数(「確定3発」)。対戦の標準の言い方 |
| `乱数` | 「乱数4発(40.0%)」。対戦の標準の言い方 |
| `特化` | 「A特化」「HB特化」 |
| `無振り` | 振り方の名前 |
| `準速` | 素早さの振り方の名前 |
| `最速` | 素早さの振り方の名前 |
| `性格` | ゲーム内の語 |
| `特性` | ゲーム内の語 |
| `持ち物` | ゲーム内の語 |
| `テラスタイプ` | ゲーム内の語 |
| `能力ポイント` | ゲーム内の語(SP)。「SP」も併記してよい |
| `実数値` | 対戦の標準の言い方 |
| `逆算` | 画面の名前。対戦の標準の言い方 |
| `仮想敵` | タイプバランスで使う。対戦で広く使う語なので残す(人間の確認待ち。ADR-0337「未決」) |
| `メガストーン` | ゲーム内の語。持ち物欄の言い方だけを直す(下の表) |
| `メガシンカ` | ゲーム内の語 |
| `ばつぐん` | ゲーム内の語(相性) |
| `いまひとつ` | ゲーム内の語(相性) |
| `急所` | ゲーム内の語 |
| `ぶつり` / `とくしゅ` / `へんか` | 技の分類。ゲーム内の語。ひらがなで書き、漢字の物理/特殊/変化にしない(技ピッカーの分類アイコンの読み上げ名。G-01、ADR-0341) |

## 言い換える語(禁止語)

左の語は画面の文言に使いません。検査(`web/src/i18n/glossary.test.ts`)がこの表の1列目を読み、
`web/src/i18n/` の文言(テスト以外の `.ts` の文字列)に含まれないことを確かめます。
例外は次の「例外」の表に書いたものだけです。

| 禁止語 | やさしい言い換え | 使う画面 | 理由・メモ |
|---|---|---|---|
| `観測` | ダメージ(「ダメージ1」「ダメージを追加」「どちらのダメージ」) | 逆算 | 内部の概念(observation)の直訳。利用者が入れるのは「対戦で見たダメージ」 |
| `推定結果` | 考えられる振り方 | 逆算 | 何が出るのかを言う |
| `近い候補` | ほぼ合う候補 | 逆算 | 何に近いのかが分からない |
| `プリセット` | 定番の振り方 | 素早さ | 開発者向けの語 |
| `指数` | 〜の目安(火力の目安・物理耐久の目安・特殊耐久の目安)/ いちばん強くなる振り方 | 調整 | 計算式の名前で、初見では意味が分からない |
| `16n` | 16の倍数(「16の倍数-1」「次の16の倍数」) | 調整 | 数式の書き方 |
| `最小の振り方` | いちばん少ない振り方(「目標に届くいちばん少ない振り方」) | 調整 | 機械的な言い方(ec レーンの依頼) |
| `API` | サーバー(「〜のサーバーに接続できません」) | 全画面のエラー | 開発者向けの語 |
| `WASM` | この端末(「この端末(オフライン)」) | ヘッダーの計算する場所 | 開発者向けの語 |
| `実行場所` | 計算する場所 | ヘッダー | 開発者向けの語 |
| `計算モード` | 計算する場所 | お気に入り | ヘッダーの見出しと同じ語にそろえる |
| `マスタ` | データ(「データにありません」「ポケモンのデータ」) | 全画面のエラー | 開発者向けの語 |
| `識別子` | 端末の情報 | 調整のエラー | 開発者向けの語 |
| `識別情報` | 端末の情報 | 素早さのエラー | 開発者向けの語 |
| `リクエスト` | 入力の内容 | タイプバランスのエラー | 開発者向けの語 |
| `ID` | 番号(「この端末に割り当てた番号」) | このアプリについて | 開発者向けの語 |
| `種族` | すべての特性(「おまかせ(すべての特性で計算)」) | 計算・逆算 | 内部の分類の語 |
| `メガシンカ:` | ふつうの文(「メガシンカするので、持ち物はメガストーンに決まっています」) | 計算・逆算・構築 | 見出し+コロンの機械的な書き方 |

持ち物欄の固定のメガストーンの表示は、「〇〇のメガストーン」をやめて「〇〇専用のメガストーン」にします
(ストーンの名前はデータに日本語名が無いことがあるので推測しない。ADR-0326 の方針は変えない)。

## 例外

禁止語を含んでよい文言です。利用者の操作では画面に出ない、開発者向けの文言・固有名詞に限ります。
「キー」が `*` のときはそのファイル全体を対象外にします。

| ファイル | キー | 禁止語 | 理由 |
|---|---|---|---|
| `judge.ts` | `*` | `*` | 判定は非表示(F-07)で、判定レーンの担当。表示を戻すときにこの用語集にそろえる |
| `about.ts` | `aboutText.dataSources.detail` | `API` | データの出典の固有名詞(PokeAPI) |
| `ja.ts` | `apiEngineText.invalidPreset` | `プリセット` | 画面の操作では起きない開発者向けのエラー |
| `ja.ts` | `apiEngineText.invalidPreset` | `API` | 同上 |

## iOS との関係

iOS の Text は Web と同じ語にします。変えた語の一覧(旧 → 新)は `docs/ai-shared/decisions/` の決定ファイルで
iOS レーンに伝えます(ADR-0337 付録)。iOS が揃えるまでの間は、Web の語(この用語集)を正とします。
