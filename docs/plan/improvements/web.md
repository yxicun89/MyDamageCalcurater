## 2026-10-04 ユーザーの動作確認の要望(データレーン 01 経由。ダメージ計算画面)
ユーザーの言葉の要約: 「この努力値の場合どれくらいか」が分からないので、能力ポイント(SP)を自分で入力し、性格補正も選びたい。桁の丸め方は今のままでよい(好評)。
技はダメージを与えるものだけにし、入力は「技を選ぶ → その技の分類の攻撃/特攻をプリセットか数値+性格で決める → 計算」の順にしたい。
ユーザーは既定案(A)で進めてよいと言っている。

- [x] **I-web-2(PR-1)**: 技の選択肢を、ダメージを与える技(物理・特殊)に絞る。変化技は出さない(マスタの分類から導く。ハードコードしない)。完了: `domain/moves.ts` の `damagingLearnsetMoves` を計算・逆算・調整の技欄に適用。変化技だけの種族は案内(`noDamagingMovesNotice`)を出し要求を送らない。`status-move` は安全網として残す。ADR-0328。
