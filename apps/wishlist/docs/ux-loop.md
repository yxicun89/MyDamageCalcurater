# 使用感の改善ループ

使ってみた感想から、直す方向を決めて、作って、また使ってもらう。この繰り返しの記録。
1 周ごとに「感想 → 原因 → 直す方針 → 作ったもの → 次に見てもらうこと」を書き足す。

## 1 周目(2026-10-11)

### 感想(ユーザー)
1. 欲しいものを足すたびに、画像・URL・ジャンルを設定するのが手間。いつも駿河屋か公式の商品ページを見ているので、入力は URL だけがいい
2. 専用の API キーやトークンは、知らない人には「何それ」になる
3. プログラムで作ったプロトタイプのような見た目。装飾のない iOS 標準の見た目は好きではない。文字で明示して伝えるのではなく、ゲームやモダンなアプリのように文字以外で伝えてほしい

### 原因
- 登録: URL からの下書きはあったが、「取得」ボタン・名前・ジャンルの選択を人がやる作りだった。登録の入口が「写真」と「URL」の 2 つあり、どちらも入力欄の並ぶフォームだった
- 接続: 設定画面に「API の URL」「トークン」が出ており、内部の仕組みをそのまま画面にしていた。Yahoo!ショッピングは appid を取らないと価格が出ない作りだった
- 見た目: 状態を文の表示(「だいたい ¥A〜¥B で買えそう」「最終取得: ○日前」など)と、標準部品の並びで伝えていた。色・形・大きさ・位置で伝える設計をしていなかった

### 直す方針
- 登録は URL を 1 つ渡すだけ。画像・名前・ジャンルはサーバーが推定し、人はジャンルのアイコンを 1 タップで確かめて「追加」する(ユーザー決定 2026-10-11)
  - iOS の共有シートからは、Safari で開いているページから画像と名前を直接読む(サーバーから読めないページにも効く)
- 接続の設定を画面から消す。8080 を 127.0.0.1 に絞り(ADR-0810)、トークンと接続画面を無くした。iPhone からは Tailscale を通す(ユーザー決定 2026-10-11)
- Yahoo!ショッピングは appid をやめ、検索ページを読む(robots.txt で許可されている範囲。ユーザー決定 2026-10-11)
- 見た目は、コレクション系ゲーム・Pinterest・ショッピングアプリの要素から 3 方向の案を作り、ユーザーに選んでもらう

### 作ったもの
- デザイン案(画面イメージ。3 方向 × ホーム・詳細と、共通の URL 登録): https://claude.ai/artifact/RohzRBrDG6zGJFnM76ra1J

### デザインの絞り込み(ユーザーの反応)
- 方向は A(コレクション棚)。ただし最初の紺×金の色味は好みでない
- 配色を 14 パターン出した → 黒・深海・白系が好み。クリーム色は好みでない
- 実画像を置くと、黒と深海は印象が違った。純白は寂しい → 薄グレー(`#f2f3f5`)と青みの白(`#edf2f8`)が好み。シルバーより濃いグレーは違う
- エフェクトは「そのまま」と「トレカ枠」が良い。ホロ枠は光が強すぎる。トレカ枠は主張が強い → わかるかわからないかくらいの、ジャンル色の細い枠(1.5px・約 35%)が良い
- ジャンルの色は設定で選べるようにする(使いながら自分で調整したい。ユーザー要望 2026-10-11)

### 決まったこと
- 配色は青みの白(詳細画面を見て決定)。他の画面も同じ配色でデザイン案を作り、全体として良いと言ってもらえた
